# Coordinate local Academy assignments

The final SITE-05 rehearsal joins actual accepted Academy rendering, authored
assignment events, the existing homepage save authority and a finite local
serving fleet. It does not install a production release registry or activate a
hosted club.

## Serving boundary

The scoped owner starts distinct current-platform builds on native loopback
listeners. It holds every root lock, validates private IPC, repeats verification
and stops owned process groups before releasing locks. The existing three-role
reconstruction proof keeps its original API and checks. The new owner supports a
finite named set and the fixed `pilot.localhost` test hostname. Supplied URLs,
ports, arbitrary hostname aliases and manufactured ready objects are refused.

Every serving capability requires an externally accepted v2 package, its exact
reconstruction marker, matching retained inputs, whole binding and complete lock,
and a verified build receipt. A generic changed build is insufficient. Both A and
B must use the tested current-platform inputs and selected public build
environment. The supported local contract records the actual Node version,
modules ABI identifier, operating system, architecture, resolved Next version
and canonical prepared dependency tree. A different contract is rejected.
Canonical dependency-path equality is not installed-byte or native-ABI attestation.

The current-platform fingerprint includes observed inputs outside the accepted
visual/binding closure and reserved reconstruction marker. Rollback selects
retained A on tested current platform B. It does not select the old platform
build. Private/custom environment equality and arbitrary future platform
compatibility remain outside the contract.

## Assignment and traffic authority

A unique unexposed local PostgreSQL schema owns immutable releases, immutable
worker incarnations and capabilities, immutable assignment events, current event
pointers, and one finite admitted-membership generation. Anonymous and ordinary
authenticated roles cannot register capabilities or change that authority.
Service-role writes use narrow trusted functions. SQL does not inspect disk.
The scoped coordinator verifies installed facts before registering them.
`createPilotSiteCoordinator` requires exclusive use of an idle local service-role
`pg.Client`. The factory owns the registration transaction, including rollback.
Do not pass a client with an existing transaction or concurrent queries.

Membership changes and activation take the existing homepage advisory lock
before row locks. Activation compares the expected event and fleet generation,
checks target and retained-current support on every admitted worker, then appends
a fresh event and updates its exact immutable legacy Academy presentation pointer
in one transaction. Rollback targets only the immediate predecessor. A/B/A cannot
revive an old token. Reassigning the already active target is rejected.

The exact legacy projection is the architecture's allowed outer adapter. The
unchanged epoch trigger advances the real homepage token. The actual
`load_homepage` and `save_homepage` functions keep authorization, content CAS,
original request hashing and actor-scoped receipt-first replay. Neither the
coordinator nor the proof translates an old token, UUID, payload or receipt.
Content-policy restrictions remain unchanged.

Resolution reads event, registered projection, actual presentation pointer and
membership in one SQL snapshot. It distinguishes published, exact legacy,
missing, invalid, unavailable and lookup-failed. A pointer changed by an outside
legacy writer invalidates authored resolution and activation. Invalid authored
state never selects another installed release.

The finite proof document guard admits new navigation only to an owned origin
for the currently assigned release on an admitted worker. A drained worker loses
new-document eligibility. Its existing full documents retain their original
origin for later font and image requests. Full documents keep shell and stylesheet
state separate. This is local document isolation, not a same-origin production
router or code modules sharing one document.

Prepared transitions are private runtime objects bound to their expected event
and membership generation. Copied or manufactured plans fail. Capabilities and
plans cannot outlive the owned scope. Child failure aborts further serving and
withholds success. Listener liveness and PostgreSQL commit are not one atomic
transaction; a process can fail while a database commit is in flight. Existing
locks and pre/post checks do not establish continuous filesystem immutability.
